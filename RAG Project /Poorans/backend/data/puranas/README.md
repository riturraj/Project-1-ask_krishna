# Puranic Texts for the Eternal Charioteer

This folder holds the text files that the AI uses to answer questions.

## How it works
1. Drop any `.txt` file into this folder.
2. Run `python ../ingest.py`.
3. The AI will now cite these texts in its answers!

## Supplied Texts
- `bhagavata_purana.txt`
- `vishnu_purana.txt`
- `shiva_purana.txt`
- `devi_bhagavata.txt`

## Adding More
If you want to add the Skanda Purana, Padma Purana, etc.:
1. Find a public domain English translation online (e.g., from wisdomlib.org or archive.org).
2. Save excerpts or the whole text as `[Name_of_Purana].txt`.
3. Re-run the ingest script.
